# Local MVP implementation plan

Contract: [API and persistence](../../architecture/mvp-contract.md).
Verification: [results and limitations](../../verification/mvp.md).

- [x] Verified API/PostgreSQL foundation with explicit schema migrations.
- [x] Domain/API: sessions, roles, cases, stored documents, policy versions and decisions.
- [x] Analysis: deterministic extraction, optional provider adapter, scoped pgvector
  retrieval, explicit rules, cited reports and separate held-out evaluations.
- [x] Durable PostgreSQL jobs, exclusive claiming, shared checkpoint/lock session,
  bounded execution, human review resume and immutable reviewed reports.
- [x] Local REST tickets with separate exact approval, idempotency and reconciliation.
- [x] Polish interface: policies, cases, context, sources, reports, decisions and history.
- [x] Compose seed, CI configuration, automated/browser checks, restart/backup/restore
  verification and public architecture/operations documentation.
- [ ] Real-model quality validation after explicit provider/model configuration and
  review of account quota, data terms and evaluation labels. Demo results do not
  complete this separate validation step.

No real external integration or public deployment is part of this local MVP.
